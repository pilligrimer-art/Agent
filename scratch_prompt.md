# Задание для Kimi: Оптимизация парсера команд среды (MCP Tools)

Текущий код агента находится в директории `C:\Users\Nich\Documents\New project 2 - Copy - Copy\agent`.

В файле `agent/output_parser.js` логика извлечения аргументов для команд среды (`MCP_LIST`, `MCP_READ`) написана нестабильно, через регулярки. Она ломается на пробелах в путях, не поддерживает множественные аргументы и не имеет защиты от галлюцинаций (Autofix).

Твоя задача — прочитать `agent/output_parser.js` и переписать парсинг этих команд.
Ниже приведён подробный план:

### 1. Единый токенизатор аргументов
Замени регулярку `combinedArgs.match(...)` для MCP-команд на надежную функцию извлечения, например `extractPaths(argsString)`. Функция должна правильно разбивать строку на массив путей, учитывая двойные `"` и одинарные `'` кавычки, чтобы пути с пробелами парсились корректно. Это позволит командам вроде `MCP_READ` принимать сразу несколько файлов (например, `[MCP_READ "file1.txt" 'file 2.txt']`).

### 2. Поддержка множественных аргументов для MCP
В основном блоке парсинга (строки ~792-808) перепиши обработку `MCP_LIST` и `MCP_READ`, чтобы они могли принимать массив путей и пушить их все в `actions.mcpLists` и `actions.mcpReads` соответственно. Если путей нет, нужно генерировать `addFailed('MCP_READ', ...)` с правильным форматом.

### 3. Интеграция с Hallucination Detector
- Добавь `MCP_LIST` и `MCP_READ` в список `coreTags` (строка ~578).
- В массиве `HALLUCINATION_PATTERNS` (строки ~146+), в группе "GROUP A: pseudo-wrappers" и "GROUP B: colon-separator", добавь поддержку извлечения для `MCP_LIST` и `MCP_READ`. Если парсер встречает конструкцию вроде `[ACTION]: MCP_READ "file"`, он должен правильно конвертировать её в легитимную команду с извлечением пути. Формат, возвращаемый функцией `extract` для MCP-команд, должен быть, например: `{ kind: 'MCP_READ', paths: ['path1'] }`.

Ожидаемый результат: отредактированный файл `agent/output_parser.js`, в котором `MCP_LIST` и `MCP_READ` корректно обрабатывают кавычки, поддерживают несколько путей, и правильно встроены в детектор галлюцинаций. Примени изменения с помощью твоих инструментов `replace_file_content`.
