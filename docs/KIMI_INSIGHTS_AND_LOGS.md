В этом документе собраны ключевые мысли, архитектурные разборы, выводы аудита и история диалогов/вызовов Kimi K3 в рамках работы над проектом.

## 1. Идеи и мысли Kimi K3 по архитектуре `AgentProject`

### 1.1. Концепция "Free Will" (Свободная воля агента)
> *"В отличии от стандартных чат-ботов, данный проект — это автономный агент. Пользователь не управляет памятью напрямую. Агент сам решает, какие факты сохранять в долгосрочную память (`MEM_SAVE`), какие цели преследовать и когда их завершать (`MEM_DELETE`)."*

- **Краткосрочные цели (Plans):** Краткосрочная память `short_mem` с `type = 'plan'` представляет собой активные цели агента.
- **Исключение из циклической авто-архивации:** По умолчанию записи `short_mem` архивируются/удаляются через 4-8 циклов. Цели типа `plan` исключены из этого правила (`WHERE type != 'plan'`), чтобы агент мог удерживать постоянные цели через произвольное число циклов.

### 1.2. Обучающий слой парсера (Parser Teaching Layer)
> *"Парсер не должен молча 'глотать' ошибки формата. При некорректных тегах среда возвращает агенту `[PARSER HINT]` с точной структурой JSON. Это позволяет модели самообучаться прямо в процессе диалога."*

## 2. Аудит безопасности и уязвимостей (Выводы Kimi K3)

Kimi K3 провел глубокий аудит системы OpenClaw x Kimi K3 и выделил критические аспекты защиты:

1. **Защита от RCE (Remote Code Execution):**
   - Перевод `ALLOWED_USERS` из `[]` вwhitelist `[8337697961]`.
   - Запрет выполнения деструктивных системных команд (`DANGEROUS_PATTERNS`).

2. **Песочница файловой системы (Sandboxing):**
   - Валидация всех путей записи `write_file` через `is_relative_to(WORK_DIR)`.

3. **Управление секретами:**
   - Вынос API-ключей в `.env` и удаление токенов из скриптов `.bat`/`.ps1`.

## 3. Логи и статистика вызовов API Kimi K3

Полные исходные логи работы сервера и вызовов API находятся в директории:
- `logs/bot.log` — Текущий лог работы aiogram 3 бота, вызовов инструментов и использования токенов.
- `logs/bot_legacy.log` — Исходный лог первично запущенных инстансов.

### Метрики использования:
- **Контекстное окно:** 1 048 576 токенов (1M context).
- **Среднее время ответа:** 2–15 секунд при базовых вызовах, 30–90 секунд при глубоких рассуждениях (`reasoning_effort="max"`).
