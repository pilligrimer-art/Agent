# 🔍 Codebase Auditor Skill

## Назначение
Проведение системного аудита репозитория за 1-3 раунда инструментов, предотвращая раздувание контекста и лимита токенов.

## Алгоритм работы (Workflow)
1. **Карта файлов (1-й раунд):**
   Запусти единую команду поиска структуры (без ухода в `node_modules` / `.git`):
   `Get-ChildItem -Recurse -Exclude node_modules,.git,dist | Select-Object FullName`
2. **Чтение метаданных:**
   Прочитай `README.md`, `package.json` / `requirements.txt` и точки входа (`index.js` / `main.py`).
3. **Пакетный вывод:**
   Не читай файлы по одному. Сгруппируй вывод по компонентам:
   - 🎯 Архитектура и назначения
   - ⚠️ Узкие места / Потенциальные баги
   - 🔒 Безопасность и лимиты
   - 🚀 Рекомендации по оптимизации
