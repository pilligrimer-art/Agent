# 🛡️ Token Guard & Context Optimizer Skill

## Назначение
Предотвращение превышения суточного лимита токенов (TPD) и оптимизация контекста.

## Правила расхода токенов
1. **Файлы документов:** Большие руководства и скиллы сохраняй в Moonshot Files API (`/v1/files`) через `moonshot_sync_skills`, не пересылая их целиком в каждом вызове.
2. **Лимит раундов:** Ограничивай число вызовов инструментов 5-12 раундами за запрос.
3. **Очистка вывода:** Обрезай массивные текстовые выводы локальных команд до 4000-8000 символов.
